# CladeForge 用户手册（中文）

**适用版本 CladeForge v0.1.0**

English version: [MANUAL_EN.md](./MANUAL_EN.md)

CladeForge 是一款本地优先的跨平台桌面应用，用于构建、注释和导出带有演化语义层的系统发育树。它将系统发育树重新定义为"假说脚手架"——一个用于构建、比较和优化演化场景的画布。

本手册按工作流程顺序，涵盖应用的全部功能。

## 1. 快速入门

### 系统要求

| 平台 | 最低系统 | 架构 | 磁盘 | 内存 |
|------|---------|------|------|------|
| macOS | 11.0 (Big Sur) | arm64、x86_64 | 实测 12.4 MiB（v0.1.0，arm64 应用包；安装镜像 4.6 MiB） | 512 MB |
| Windows | 10 (64位) | x86_64 | 尚未实测——本版本未产出 Windows 构建 | 512 MB |
| Linux | glibc ≥ 2.28 | x86_64 | 尚未实测——本版本未产出 Linux 构建 | 512 MB |

应用自身不捆绑浏览器引擎，但它会渲染进操作系统自带的 web 视图（macOS 上为 WKWebView、Windows 上为 WebView2、Linux 上为 WebKitGTK），因此宿主机必须提供对应的 web 视图；运行本应用不需要任何其他运行时（Java、Python 或 Node.js）。

### 安装

**预构建二进制包** — 从项目发布页下载对应平台的发布版本：
- macOS：`.dmg`（同时支持 Apple Silicon 和 Intel）
- Windows：`.msi`（x64）
- Linux：`.deb` 或 AppImage

**从源码构建** — 克隆仓库：

```bash
git clone https://github.com/ZengZichao/CladeForge.git
cd CladeForge
npm install
npm run dev            # Web 开发服务器（无需 Rust 工具链）
npm run tauri dev      # 桌面开发构建
npm test               # 运行 Vitest 测试套件
npm run tauri build    # 构建打包的 .app / 安装包
```

前置条件：Node.js ≥ 18，Rust 工具链 ≥ 1.70，npm。

### 首次启动

首次启动时，CladeForge 打开一个空工作区，并询问是否开始四步新手指南——该导览是显式选项，关闭提示后直接进入空画布。可随时通过顶栏的「**新手指南**」按钮（与快捷键速查按钮并列）、按 ⌘K 在命令面板中搜索"新手指南"，或从快捷键速查对话框重新打开。指南依次介绍画布、检视面板、模块栏和命令面板。

快速开始的方式：
- **导入树** — 将 `.nwk`、`.newick`、`.tree`、`.tre`、`.nex` 或 `.nexus` 文件拖到窗口上，或在文件菜单中选择「导入树」。⌘O / Ctrl+O 是**打开项目**，读取的是 `.cladeforge.json` 文件。
- **从零开始构建** — 选中根节点后点击顶栏的「＋添加子节点」按钮，在一个对话框内即可完成二叉、三叉与多叉分裂。
- **载入示例项目** — 在空状态界面点击"载入示例树"或从示例选择器中选择一个示例。内置六组示例，涵盖古菌域演化、细菌域演化（含蓝细菌产氧光合作用）、病毒演化（RNA/DNA基因组类型）、鲸类水生适应、植物陆地登陆演化（维管组织与种子）、四足动物陆地演化（四肢、羊膜卵与飞行），每组示例均预置性状、演化事件和假说层。

### 语言与主题

- **语言** — 首次启动时跟随操作系统语言，之后记住你的选择。随时在语言切换器在中英文之间切换，界面立即重新渲染，内置示例自带的节点标签也一并切换。
- **主题** — 默认跟随系统。在语言切换器旁的主题切换器中选择浅色、深色或跟随系统。
- **顶栏控件** — 顶栏包含视图模式切换（标准视图 / 协同视图）、「＋添加子节点」按钮、撤销与重做、项目名、保存、语言与主题切换、快捷键速查（⌘?）和「新手指南」按钮。结构编辑在节点的右键菜单与命令面板中，不在顶栏。

## 2. 界面概览

CladeForge 采用三栏布局，专为高效的系统发育工作流设计：

```
┌───────────────────────────────────────────────────┐
│                    标签栏（顶部）                    │
├──────────┬───────────────────────────┬──────────┤
│          │                           │          │
│  模块    │       画布（中部）          │ 检视面板  │
│  面板    │      树可视化              │ （单对象  │
│  （左）  │                           │  属性）   │
│          │                           │          │
└──────────┴───────────────────────────┴──────────┘
```

### 左侧 — 模块面板

按三个分组组织：

| 分组 | 模块 | 用途 |
|------|------|------|
| **内容** | 性状 · 假说 · 协同 · 时间 | 定义性状、管理假说层、运行 DTL 协同重建、配置时间校准 |
| **展示** | 样式 | 全局布局与样式 |
| **输出** | 分析 · 导出 | 推理辅助与文件导出 |

每个模块都是可折叠的小节。固定展开可保持其展开；取消固定则允许其折叠。

### 中部 — 画布

主要工作区，用于显示和编辑系统发育树。支持平移、缩放、节点拖拽、重定父、连线创建和多选。结构操作、定根、布局切换与视图控制位于节点的**右键菜单**和**命令面板**中；画布上的悬浮控件栏承载搜索框、放大/缩小与适应窗口。

画布角落的**缩略图**提供大树的概览导航。

当枝长对当前布局有意义时会绘制**比例尺**；可折叠的**画布图例**列出屏幕上现有的性状颜色、状态转变、事件符号与时间标注。从未记录枝长的分支以灰色虚线绘制并在图例中说明，以免"没有数据"被误读为"枝长为 0"。

### 状态栏

底部状态条报告的是画面实际情况：节点数、边数、当前缩放百分比（适应窗口时被压缩到下限会一并注明），以及选中对象数。正好选中两个节点时会追加"最近共祖已标橙环"提示。它还显示自动保存状态，见[自动保存与恢复](#自动保存与恢复)。

### 小窗口布局

窗口宽度约小于 1024 px 时，界面切换为紧凑排布：模块栏变为底部标签条，左右面板变为各自带关闭按钮的浮层，⌘. 可显示或隐藏它们。面板之间的分隔条可在 180 至 620 px 之间拖动，宽度会在下次启动时保留。

### 右侧 — 检视面板

当你在画布上选中一个节点或自定义连线时，检视面板显示该对象的所有可编辑属性：名称、枝长、支持率、年代、样式覆盖、性状状态、演化事件和置信度/证据元数据。继承全局默认的属性标记为"继承全局默认"；已覆盖的属性标记为"已覆盖全局默认"。

检视面板支持搜索：在"搜索属性…"栏输入即可直达某个属性，常用属性可点星标固定到顶部的**收藏**分区。每个分区标题会统计该对象在此分区覆盖了多少项属性，分区旁的说明提示可以关闭。哪些分区处于展开、收藏了什么、关闭过哪些提示，都按语言分别保存，下次打开时保持原样。

节点的标签另有位置控制：九个锚点方位加一个"自动"方位（自动选择背离父节点的一侧），并可分别设置 X/Y 偏移做微调。

### 命令面板（⌘K）

随时按 ⌘K（macOS）或 Ctrl+K（Windows/Linux）打开命令面板，再按一次关闭。约三十五条命令分为七个类别——文件、编辑、树操作、视图、分析、协同、帮助——每条都带图标与对应的键盘提示。

输入即可过滤。命令会同时匹配显示名称、英文别名，以及中文名的**拼音**，因此输入 `dakai` 能找到"打开项目"，输入 `baocun` 能找到"保存项目"。用 ↑/↓ 移动，Enter 执行。

有少数操作只存在于命令面板中：把选中的子树提取为新标签页、导入基因树、进入或退出协同视图、导出协同重建报告，以及重新打开新手指南。

### 标签页

CladeForge 支持多标签页，每个标签页持有一个独立项目。点击标签页即可切换，点击其 × 按钮关闭，点击标签栏末尾的 **+** 按钮新建标签页。下次启动时自动恢复标签页；损坏的标签页会被跳过并通知。

## 3. 树编辑

### 创建拓扑

| 操作 | 方式 | 位置 |
|------|------|------|
| 添加二叉 / 三叉 / 多叉分支 | 选中节点 →「＋添加子节点」，再选择分裂方式 | 顶栏按钮打开同一个对话框；右键菜单提供同样的选项，包括分支数量与硬/软多分叉类型 |
| 添加同级 | 右键节点 →「＋同级」 | 右键菜单或命令面板 |
| 插入父节点 | 右键节点 →「插入父节点」 | 在选中节点与其父节点之间插入一个节点 |
| 删除节点 | 选中 → Delete / Backspace | 有风险的删除先弹出确认，提示条中的撤销只回退这一次删除 |
| 重命名节点 | 双击节点 | 行内编辑 |

### 重定父与定根

- **重定父** — 按住 Alt 并将节点拖到另一个节点上，拖动的节点会成为目标节点的子节点。
- **以选中节点定根** — 右键 →"以此节点定根"，或在命令面板中执行。会弹出确认，因为定根会重排整个拓扑。
- **中点定根** — 在最长路径的中点处定根（需要枝长数据）。
- **外群定根** — 右键 →"设为外群并定根"。

### 折叠与阶梯化

- **折叠/展开** — 右键节点 →"折叠子树/展开子树"。折叠的子树显示为三角形标记。
- **阶梯化（升序/降序）** — 在每个节点处按子树大小排列子节点，使树形更紧凑易读。可从右键菜单或命令面板执行。

### 自定义连线（网状关系）

除树拓扑外，CladeForge 还支持自定义连线，用于表示网状演化事件（杂交、水平基因转移等）：

1. 悬停节点 — 其右上角会出现一个小圆形**端口**。
2. 从端口拖到另一个节点即可创建自定义连线。
3. 在检视面板中配置连线的标签、颜色、线宽、线型、箭头和弯曲度。
4. 选中连线后按 Delete，或右键连线删除。

### 多选

- **Shift + 点击** 选择多个节点。
- 选中两个节点时，它们的**最近共祖（MRCA）**会以橙色环高亮显示。
- 检视面板显示批量编辑选项（填充色、描边色、节点大小、标签颜色、字号、分支颜色、显示/隐藏标签、删除所选）。

### 搜索

用画布控件中的放大镜按钮或 ⌘F / Ctrl+F 打开搜索框，按标签查找节点。匹配的节点在画布上高亮并给出计数。在查询前加 `type:leaf` 或 `type:internal` 可只在末端节点或内部节点中命中，按 Enter 在匹配项之间循环。

## 4. 布局与可视化

### 布局类型

| 布局 | 描述 |
|------|------|
| **矩形分支图** | 等深度步进；忽略枝长。经典出版物风格。 |
| **矩形枝长图** | 枝长决定水平位置；末端不对齐。 |
| **地质时间图** | 节点按已记录年代排在真实时间轴上；地质年代条带与环境事件叠加其上。内部标识为 `time-calibrated`。 |
| **环形图** | 径向布局；等角度或基于枝长。 |

### 方向

每种布局均支持四种方向：
- **LR** — 从左到右（默认）
- **RL** — 从右到左
- **TB** — 从上到下
- **BT** — 从下到上

### 布局模式

- **自动** — 节点根据布局类型和间距参数自动定位。
- **手动** — 可拖拽单个节点覆盖其位置。固定的节点被自动布局忽略。在样式模块中使用**重新排布**（或命令面板）清除所有手动位置并重新自动排布。

### 间距

在样式模块面板中调整**层级间距**（深度级别之间的水平间距）和**同级间距**（相邻末端之间的垂直间距）。

### 支持率阈值

项目会保存一个**支持率阈值**（0–100，默认 70）。它唯一生效之处是导出图：在导出的 SVG 中，低于阈值的支持率标签以淡雅的坐标轴灰印出，而不是纯黑，从而在出版用图中让低支持率的节点"看起来就弱"。以 0–1 保存的后验概率会先换算为百分比再比较；没有任何支持率数据的树不受影响。

该阈值属于项目数据：它从项目文件中读取，**样式面板不提供对应的控件**。

### 颜色渐变

在样式模块中启用基于深度的分支颜色渐变：未单独设色的分支从根部颜色插值到末端颜色。

## 5. 性状与状态

性状系统是 CladeForge 演化语义层的核心。它让你将特征映射到树上，并可视化其分布、状态转变和祖先状态。

### 创建性状

1. 打开**性状**模块（左侧面板，内容分组）。
2. 点击「＋新建性状」。
3. 输入名称并选择类型：
   - **离散** — 定义一组命名状态，每个状态带颜色（如"水生"=蓝色，"陆生"=绿色）。
   - **连续** — 定义数值范围，带低值颜色和高值颜色渐变。
4. 可选添加描述。

### 分配状态

- **末端节点（叶）** — 已知/观测状态。可通过**性状矩阵**对话框（在性状模块中点击"性状矩阵…"）或逐个在检视面板中分配。
- **内部节点** — 这些是你的*祖先状态假说*。在画布上选中一个内部节点，然后在检视面板的"性状状态"区域分配其性状状态。每个分配可附带置信度（高/中/低）和支持/反对证据文本。

### 性状矩阵

性状矩阵对话框提供所有末端 × 所有离散性状的表格视图，是输入观测数据最快的方式。仅列出叶节点；内部节点的祖先状态假说在画布检视面板中设置。

### 桑科夫步矩阵

对于离散性状，可定义可选的**代价矩阵**（桑科夫步矩阵），指定不对称转变代价。矩阵编辑器支持对称模式（只需编辑上三角，下三角自动镜像）。代价矩阵影响简约法建议和一致性检查。使用"重置为等权"可恢复为 Fitch 简约法（对角线为0，其余为1）。

### 颜色映射

在性状模块中，使用"着色依据"下拉菜单按性状状态对节点和分支着色。状态转变可选择在分支上以标记显示。

### 缺失与不适用数据

- **缺失（?）** — 状态未知/未观测。
- **不适用（-）** — 该性状不适用于此分类单元。

## 6. 演化事件

CladeForge 按六个分组提供共 15 种内置演化事件类型——物种形成、灭绝、关键演化、基因流、生物地理，以及仅包含用户自定义类型的"通用"组。事件由用户*手动标注*——代表你对树上特定位置发生了什么的假说。

### 事件目录

| 分组 | 事件（徽章代号） |
|------|------|
| **物种形成** | `AL` 异域成种、`SY` 同域成种、`PA` 邻域成种、`PO` 多倍化成种 |
| **灭绝** | `LX` 本地灭绝、`MX` 大规模灭绝 |
| **关键演化** | `KI` 关键创新、`AR` 适应辐射、`BN` 瓶颈效应 |
| **基因流** | `HG` 水平基因转移、`HY` 杂交 |
| **生物地理** | `DI` 扩散、`VI` 隔离分化、`RE` 区域灭绝 |
| **通用** | `CU` 自定义事件 |

每种事件类型都有一个徽章代号——取自其英文名称的两个大写字母——以及颜色和默认位置（节点、分支或两者皆可）。画布上代号画在对应颜色的圆环内，图例、检视面板和类型下拉菜单始终按界面语言写出完整名称。代号是纯文本，因此徽章导出为 SVG、PNG、PDF 时与屏幕上完全一致，灰度印刷同样可读。放置事件时可以改写该位置。

### 放置事件

1. 在画布上选中一个节点。
2. 在检视面板中滚动到**演化事件**区域。
3. 点击「＋添加事件」。
4. 选择事件类型、位置（节点或分支），可选输入标题和描述。
5. 设置置信度和支持/反对证据。

### 因果链

事件可在因果链中链接——例如，某分支上的关键创新*触发*了子节点的适应辐射。在事件编辑器中，使用**触发**下拉菜单链接事件。当事件叠加层可见时，因果链链接以连接弧线在画布上显示。

### 显示/隐藏事件

在**假说**模块中切换事件叠加层的显示/隐藏。可见时，事件徽章出现在节点和分支上，画布图例同步列出所用代号。

## 7. 假说层

CladeForge 支持在共享树拓扑上管理多个竞争性演化假说。

### 工作原理

- **末端（观测）状态在所有层间共享** — 它们代表经验数据。
- **内部节点的祖先状态假说和事件按层分异** — 每层是一个独立场景。
- 只有**活跃层**存在于树节点上；非活跃层单独存储，切换时恢复。

### 管理层

打开**假说**模块（左侧面板，内容分组）：
- **新建** — 创建空白假说层（复制共享末端状态；无内部节点假说）。
- **复制** — 克隆当前层（包括所有假说和事件）作为替代方案的起点。
- **删除** — 删除一个层。删除活跃层会切换到其他层。
- **切换** — 在模块的下拉框中选择要激活的层，画布立即更新。

### 工作流程示例

1. 构建树拓扑并分配末端状态。
2. 创建层A（"基于形态"）并设置祖先状态假说。
3. 复制为层B（"基于分子"）并修改冲突节点。
4. 在层间切换以并排比较场景。
5. 分别导出每层的假说 JSON 以便比较。

## 8. 推理辅助

推理辅助提供*建议性*提示——不会覆盖你的假说。由你决定采纳哪些建议。

打开**分析**模块（左侧面板，输出分组），点击"推理辅助…"，或使用 ⌘K 命令面板搜索"推理辅助"。

该模块首先是一份实时摘要，其次才是一排按钮：它报告树的末端数与节点数，以及当前假说已经蕴含的结果——简约代价、每个性状的 CI/RI、被标记的一致性问题数、存在共变关系的性状对——让你先判断值不值得细看，再打开完整对话框。其控件涵盖性状矩阵、推理辅助、运行与清除 ASR，以及跳转到某个性状的分析。

### 简约法（桑科夫）

- 使用桑科夫算法和你的步矩阵（或无则用 Fitch 等权）计算最小代价的祖先状态重建。
- 建议针对**分析**模块中当前选状的性状计算——没有需要先点的"批量生成"按钮。
- 在画布上选中内部节点，检视面板会把建议状态与你已断言的状态并列显示。点击**采纳**才会接收，否则保持原样：不经这一点击，任何内容都不会进入你的假说。
- 若某节点存在多个等价最优状态，会报告模糊性而不是默默替你选一个。

### Mk 模型概率性 ASR

基于 Mk（Markov-k）模型的祖先状态重建，模型参数在对话框的「**ASR 模型设置**」中配置：

- **速率模型** — 目前只实现 **ER（等速率）** Mk 模型：闭式转移概率矩阵仅对 ER 成立，因此不提供 SYM 与 ARD 选项。
- 使用 Felsenstein 剪枝（下行遍历）+ 兄弟/父节点上行遍历计算边际后验概率。
- 所有似然计算在**对数空间**（log-sum-exp）中进行，防止大树下溢。
- 速率按平均枝长归一化，使结果与相对枝长的绝对尺度无关。
- 结果以**饼图**形式显示在内部节点上，展示状态概率分布。
- **显示阈值**（"仅显示概率 > 阈值的状态"）只是渲染层开关：后验低于阈值的扇区不再绘制，当某一态的后验达到 1 − 阈值（其余态必然全部落在阈值之下）时整盘按该态填实色。该阈值绝不参与似然计算。

枝长异常是**分类报告**而非默默修补，因为这四种情形含义不同——"未设置枝长"并不等于"枝长为 0"：

| 结果摘要报告的降级类型 | ASR 的处理方式 |
|----------------------|---------------|
| 未设置枝长 | 按 1 代入 |
| 枝长记录为 0 | 按 0 参与计算——这是真实的同期分化 |
| 负枝长 | 无效，按 1 代入 |
| 非有限枝长 NaN/∞ | 无效，按 1 代入 |
| 后验崩塌（全为 −∞） | 退回均匀分布 |

结果摘要会给出每一类涉及的节点数，或明确说明"无降级告警"。

从分析模块或命令面板（"Mk 概率重建"）运行 ASR。使用"清除重建"清除饼图。

### 系统发育信号（CI/RI）

为每个离散性状计算：
- **一致性指数（CI）** = m/s，其中 m = 最小可能步数，s = 实际步数。
- **保留指数（RI）** = (g−s)/(g−m)，其中 g = 最大可能步数。
- 值越接近1表示性状与拓扑越一致；偏低提示同塑（趋同/平行演化），值得作为假说探究。

需要 ≥3 个已赋值末端和 ≥2 个状态。

### 一致性检查

一致性检查器标记潜在问题：
- **模糊重建** — 节点存在多个等价最优状态。
- **同塑** — 状态变化次数超过最小值。
- **缺失数据影响** — 缺失数据影响重建。
- **局部不一致** — 性状与局部拓扑冲突。
- **过多变化** — 变化次数超出预期。

### 性状相关性

性状相关性分两层报告，因为重叠比本身并不是显著性检验。

**描述性重叠。** 对每一对离散性状，CladeForge 先用简约法重建它们的状态变化，再计算两者"变化枝集合"的 **Jaccard 重叠比**（共享变化枝 ÷ 两集合的并）。只要两个性状各自至少有 2 条变化枝，该性状对即进入统计。面板会列出每一对的：

- Jaccard 重叠比，达到 ≥ 0.5 时高亮提示；
- 共享变化枝数，以及两个性状各自的变化枝数；
- 独立假设下的期望重叠 `|A|·|B|/|N|`（N 为树上全部分枝数）；
- `n` = 同时被赋值两个性状的末端节点数。

重叠比高只说明这对性状值得深究——既不等于显著，也不等于因果。

**树约束置换检验。** 点击**运行树约束置换检验**才能得到真正的 p 值。检验把性状 B 的状态在其已赋值的末端之间重新洗牌（保持 B 的边缘状态频数与缺失模式不变），然后在同一拓扑、同一简约步矩阵下重算 B 的最简约变化枝集，统计量仍是同一个 Jaccard 重叠比。p 值为单侧：

```
p = (1 + 统计量 ≥ 观测值的置换次数) / (置换次数 + 1)
```

默认运行 999 次置换，因此可报告的最小值以 `p < 0.0010` 的形式给出，而不是 `p = 0`。随机数生成器使用固定种子，因此项目未改动时重复运行会得到相同结果；面板同时报告置换零分布的均值，便于判断观测值偏离零分布中心的程度。

**多重比较。** 重叠比最高的 24 个性状对进入检验族，族内所有 p 值统一做 **Holm–Bonferroni** 校正；只有校正后的 p 才支持"显著（≤ 0.05）"的判定，未校正的原始 p 仍并列显示并明确标注。超出上限的性状对会标注为未纳入，且不给任何结论。

**适用边界。** 当某个性状对已赋值的末端少于 3 个，或树太大以致置换计算预算内剩余重复次数不足时，该对无法检验，仅保留描述性重叠比。该检验置换的是观测值而非演化路径，它**不是** Pagel (1994) 关于关联转变率的似然比检验，CladeForge 也未实现后者。

### 树摘要统计

- 末端节点数、内部节点数、分辨率（二叉率）
- 平均枝长与总枝长、树高（root-to-tip）——记录有枝长时以枝长为单位，完全无枝长时以边数（拓扑层数）为单位。未记录枝长的枝条在总枝长按 0 计入；面板会说明多少条枝记录有长度、多少条没有，因为 0（真正的同期分化）与"未记录"并不等价。
- Sackin 索引与 Colless 索引（树平衡度量）。含多分叉的树所给的 Colless 值是 max−min 的多歧推广变体，未按节点数归一化，因此**不能**与二叉树的 Colless 值直接比较；面板会说明有多少个内部节点是非二叉的。

### 连续性状

- **Blomberg's K** — 相对布朗运动的**点估计**（BM = 1）：K > 1 表示比 BM 预期更聚集，K < 1 更分散。CladeForge 不运行置换也不做 BM 模拟检验，因此程序不据该数值下演化结论：K 与 1 的差可能整个落在随机变异的范围之内，面板会把这一点明确写出。
- 每个 K 都伴随**枝长覆盖**说明。全部枝条都有长度时会报告 n/n 条枝使用所填长度；只测了一部分时会提醒其余枝按 1 代入，此时得到的是*拓扑*（分支图尺度）的 K，而不是年代尺度的 K——在跨树比较 K 时这个差别很重要。
- 至少要有一个已赋值的连续性状才会给出 K。无法计算时面板说明原因，而不是硬凑一个数字。

## 9. DTL 协同重建

CladeForge 实现了基于加倍-转移-损失（DTL）动态规划求解器的基因树/物种树协同重建。

### 设置

1. **当前项目的树即为物种树**。
2. 打开**协同**模块（左侧面板，内容分组）。
3. 点击**从文件导入基因树**（Newick 或 Nexus 文件）或**从打开的标签页导入**（由另一个已打开的项目充当基因树）。
4. 基因树的末端按名称匹配到物种树的末端。未匹配的末端会被明确报告而非悄悄丢弃，归一化后发生碰撞的标签也会被点出。

该模块可**同时容纳多棵基因树**。每条记录显示名称、成功映射到物种树的末端数目，场景存在错误或警告时还会带角标。点击记录即设为当前基因树，聚焦时按 Enter 同样可以；记录支持重命名与移除，移除会请求确认。下文所有操作都只作用于当前那棵基因树。

### 手动细化

导入后，可手动细化协同重建：
- 在协同视图中选中一个基因节点。
- 在检视面板中设置其**物种树映射**、**事件类型**（物种化 σ、加倍 δ、转移 τ）和入支**损失数**。
- 使用**按 LCA 生成建议**自动将未解析的内部基因节点映射到其在物种树中的最近共祖。
- 一致性检查器报告映射冲突和事件不一致。

### DP 求解器

1. 在协同模块中设置**加倍 δ**、**转移 τ** 和**损失 λ** 的代价。
2. 点击**计算最优解 (DP)** 运行动态规划求解器。
3. 求解器返回最小代价场景和回溯事件分配。
4. 点击**将最优解应用为假设**，将求解器结果加载为手动细化的起点。
5. 比较当前场景代价与 DP 最优代价。

结果的说明文字直接交代求解器自己的适用范围，不需要你从输出反推：

- **可比性。** 这是最小代价的*简约*协同重建，不是似然。三处有意为之的建模选择使它的事件数与损失数绝对值**低于** RAINIEFF、RaGTeP 与 Treerecon：基因树根可自由落在物种树内部而不为"基因家族的到来"付费；谱系经过物种节点但不进入旁支时不按次数计费；不受约束的物种分支不预支推测性损失。因此引用结果时应写作"本模型下的事件数"，不可当作与别的程序可互换的计数。面板在采用自由根时也会同时说明该代价不含根转移费。
- **模糊性。** 存在同代价其他事件类的节点会被计数并报告——即经典的加倍/物种化不可区分，以及镜像的转移方向。显示的事件是按既定优先序"加倍 › 物种化 › 转移"选定的那一个，这与"它是唯一最优解"不是同一回事。
- **损失记账。** 损失按内部枝与基因末端枝分列报告，因为末端枝的损失在此是计入的。
- **场景与最优。** 当前场景代价与 DP 最优代价是同一场景在同一代价向量下的两次计价，因此相等是有意义的：它说明你的假说在*这一组代价*下已经最优。

**清空假设**一步清除当前基因树的全部映射与事件假设，确认框会说明该操作可以撤销。代价在输入时即接受校验：非法的代价向量会被拒绝并回退到合法默认值，同时弹出提示说明哪里不合法——求解器不可能运行在你其实没有选择的代价上。

编辑过程中，模块会为当前基因树持续更新计数：物种化 σ、加倍 δ、转移 τ、损失 λ，以及已定标的内部节点数。

**要求：** 求解器需要二叉基因树。多分叉会破坏谱系记账——请先解决多分叉。物种树可以是任意分支数。

### 协同视图

点击**进入协同视图**进入并排显示：左侧为物种树，右侧为基因树，中间以映射线连接。点击基因节点查看并编辑其 DTL 假设。Alt+点击物种节点可设置所选基因节点的映射。**Esc** 退出该视图，顶栏的视图模式切换同样可以。

协同检视面板提供：物种树映射的下拉选择、事件类型（并可单独清除）、入支的损失数、该节点的置信度与支持率及支持/反对证据，以及对含末端的演化枝而言它涵盖多少个末端。

### 一致性校验

一致性检查在每次编辑后重新运行，并逐条列出发现的问题，每条都带类型标签：

| 标签 | 标记的问题 |
|------|-----------|
| **未匹配** | 基因末端找不到同名的物种末端 |
| **未解析** | 基因内部节点尚未给出映射或事件判定 |
| **悬空** | 映射指向了一个已不存在的物种节点 |
| **冲突** | 事件与自身的映射矛盾——非二分物种节点上的物种化，或没有目的支系的转移 |
| **可疑标记** | 归一化（大小写、下划线）后与其他标签碰撞的末端；它会被留作未映射，不参与协同重建 |
| **损失不足** | 记录的损失数少于映射应有的数量 |
| **时序** | 相互矛盾的先后关系 |
| **尖端事件** | 在基因末端上断言了事件，而末端只有映射才有意义 |

每条分为**错误**与**提示**两级，点击即可定位到相关节点——若协同重建可用则直接进入协同视图。完全一致的树会报告"无异常"，而不是留下一个空框。

## 10. 时间校准

### 时间状态的判定

时间模块在你动手之前先说明这棵树在时间维度上处于什么状态：

| 面板提示 | 含义 |
|---------|------|
| 当前为纯拓扑树，无时间数据。时间轴与环境事件不可用 | 没有任何节点带有年代。请先设置节点年代、添加校准点，或按拓扑估算年代 |
| 已检测到时间数据，时间轴功能可用 | 年代已具备，时间轴可以绘制 |
| 时间数据已具备，但当前布局为「…」，切换到「地质时间图」后显示时间轴与环境事件 | 数据有了，布局不对。点击面板中的**切换到地质时间图**按钮 |

### 地质时间图布局

在样式模块把布局类型切换为**地质时间图**（或使用上面那个按钮），让节点排在真实时间轴上：

1. 在时间模块设置**时间单位**。该栏接受自由文本，能识别 `Ma`、`ka`、`Ga`、`Myr`、`yr` 这些常用符号。无法识别的单位仍会作为轴标签显示，但地质年代条带会随之隐藏——软件无法把自己理解不了的尺度套到显生宙的时间表上。
2. 在检视面板中为每个节点输入**年代**（距今时间）。
3. 节点按年代排在时间轴上，轴以刻度线和标签绘制。
4. 未填年代的节点按现生（年代 0）处理。面板会统计这类节点的数量并列出它们的名字，避免一片末端被悄悄压在同一水平线上。

### 地质年代条带

在时间模块中开启年代条带，把地质时间的彩色条带绘制在树的后方，并选择**显示级别**：仅显示宙、仅显示纪，或宙、纪都显示。

### 化石校准点

校准点记录的是"该节点不早于/不晚于某个年代"的证据：
1. 在时间模块中打开**校准点**区域。
2. 点击「＋添加校准点」。
3. 选择节点并输入最小和最大年代。

校准点的作用边界是明确的，面板也会直接说明：它们随 **NEXUS 导出**交给下游的定年分析使用，**不会**在 CladeForge 内部反算节点年代，也不会绘制在画布时间轴上。你在屏幕上看到的年代，就是你自己（或估算器）填进去的那些。

### 单节点时间约束

同一份校准数据也镜像到节点自身。选中节点后，检视面板的「**时间约束**」分区会显示它的最小与最大年代；绑定是双向的，在两处任意一处修改，另一处都会同步更新。

### 环境事件

在时间轴上叠加有年代的环境背景：
1. 在时间模块中打开**环境事件**区域。
2. 点击「＋添加环境事件」。
3. 输入标签、时间范围（起/止，单位 Ma）、颜色和可选备注。
4. 环境事件以彩色条带或线条绘制在时间轴上（如气候变迁、大陆漂移、大灭绝等）。

### 年代估算

**按拓扑估算年代**依据拓扑深度给节点赋年代——即该节点距根的边数，按树中已有的最大年代做缩放。它不读取枝长，因此产出的是相对次序，不是带年代的系统发育树。

以此方式填入的节点会保留来源标记：面板会提示本树的部分年代属于拓扑估算而非化石/校准证据，说明它们以边数为单位，并提醒在用于分析或投稿前逐项核对。每个估算出的年代仍可在检视面板中修改，把估算值替换成真正的校准证据正是从这里入手。

## 11. 样式与主题

### 样式预设

在样式模块的"样式预设"中快速切换整体外观：

| 预设 | 背景 | 节点 | 分支 |
|------|------|------|------|
| **默认** | 白色 | 白色填充，深色描边 | 深灰 |
| **期刊黑白** | 白色 | 白色填充，黑色描边 | 黑色 |
| **演示彩色** | 浅灰蓝 | 蓝色填充 | 蓝色 |
| **暗色** | 深暖色 | 深色填充，浅色描边 | 柔灰 |

应用预设时保留单对象覆盖。

### 单对象样式

在画布上选中任意节点或连线，在检视面板中单独设置其样式：

**节点：**
- 形状：圆形、方形、菱形、无
- 大小、填充色、描边色、描边宽度
- 标签：显示/隐藏、颜色、字号、字重（300–900）、斜体、加粗、旋转角度

**分支（进入节点的边）：**
- 形状：细线、粗矩形、圆头粗线
- 颜色、线宽、线型（实线/虚线/点线）

**自定义连线：**
- 标签、颜色、线宽、线型、箭头、弯曲度

在检视面板中使用**恢复默认**清除某对象的所有样式覆盖。

### 分支渐变

在样式模块中启用基于深度的颜色渐变：未单独设色的分支从根部颜色插值到末端颜色。

### 画布设置

样式模块提供**画布背景色**与自定义连线的**默认连线颜色**两项设置，二者都会直接影响导出图像。画布尺寸属于项目架构字段，但面板暂未提供编辑入口——导出图像按树自身的范围定尺寸。

## 12. 导入与导出

### 导入

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| **Newick** | `.nwk`、`.newick`、`.tree`、`.tre` | 解析枝长与支持率，NHX 注释无损往返。有根标记 `[&R]` / `[&U]` 与显式的 `[&support=…]` 会被读入并写回，树进来时带着什么，出去仍带着什么。自动识别含多棵树的文件。 |
| **Nexus** | `.nex`、`.nexus` | 读取每个 `TREES` 块中的**全部** `TREE` 语句，并支持可选的 `TRANSLATE` 翻译表——不只取第一棵。含多棵树的文件会转入多树对话框。 |
| **多树文件** | — | 如文件包含多棵树，对话框让你选择一棵、全部导入为多个标签页或构建共识树（严格共识或 50% 多数规则）。 |

支持拖放：将文件拖到窗口任意位置即可导入。

纯 Web 版在两个方向上同样可用，只是把桌面的原生文件对话框换成浏览器下载与 `<input type="file">`。变化的只是文件如何落到磁盘，格式与选项都不变。

导出 PNG、PDF、SVG 时会显示忙碌遮罩，大树可能需要一秒以上——遮罩的作用正是避免把"仍在渲染"误认为"卡死"。

### 导出

打开**导出**模块（左侧面板，输出分组）或使用 ⌘K 命令面板。面板中的按钮按格式族分组——矢量图、位图、数据文件、报告：

| 格式 | 分组 | 描述 |
|------|------|------|
| **SVG** | 矢量图 | 出版级矢量图。WYSIWYG——与画布完全一致。包含语义层（性状着色、状态转变、事件、时间轴、自动图例）。 |
| **PDF** | 矢量图 | 用于打印/出版的矢量 PDF（jsPDF + svg2pdf.js）。由 SVG 生成。 |
| **PNG** | 位图 | 由 SVG 栅格化的 2× 位图。该倍率目前是固定值——尚无调节控件——当画布大到逼近浏览器 canvas 上限时，实际倍率会被下调以保证导出能够完成。 |
| **Newick** | 数据文件 | 树拓扑，含枝长和支持率。 |
| **Nexus** | 数据文件 | 完整 Nexus 文件，可选包含 CHARACTERS 块、ASSUMPTIONS 块（假说层）、MrBayes 块和 BEAST 块。 |
| **假说 JSON** | 数据文件 | 带版本的存档（`kind: "hypothesis-export"`，自有架构版本 `0.1.0`），内容为**活跃层**：每一个末端的状态（无论是否已赋值）、事件、置信度与证据，以及假说层的元数据。逐层分别导出即可用于比较。 |
| **R 脚本** | 数据文件 | 自包含的可执行 R 脚本（唯一依赖：`ape` 包），可在图形界面之外重新生成图形并重跑桑科夫简约法与 Mk 模型 ASR。 |
| **协同重建报告** | 数据文件 | DTL 协同重建场景的 Markdown 摘要。 |
| **叙事报告** | 报告 | 树、性状、事件和假说的 Markdown 摘要。 |

### Nexus 导出选项

该对话框由**导出**模块中的 Nexus 按钮打开。文件菜单里的 Nexus 项按默认选项直接导出、不打开对话框，因此需要下列内容时请走导出模块。

对话框可选择包含：
- **性状矩阵**（CHARACTERS 块）
- **假说层**（ASSUMPTIONS 块）
- **MrBayes 块**（用于贝叶斯推断）
- **BEAST 块**（用于分化时间定年）

### WYSIWYG 导出

SVG 导出从零生成（非克隆实时 DOM），确保紧密裁剪、无编辑杂项、路径/标签与画布完全一致。当语义层处于活跃状态时，导出包含性状着色、状态转变、事件徽章、因果链链接、时间轴、年代条带、环境事件和自动生成的图例。

## 14. 项目文件格式

CladeForge 项目以 JSON 格式存储，扩展名为 `.cladeforge.json`。当前架构版本为 **0.1.0**。

文件是一层信封而非裸项目：`app`（`"CladeForge"`）、`version` 与 `project`（即下文所列内容）。载入时会经过一道显式的、按序执行的版本迁移步骤，它是为将来的架构变更准备的：`0.1.0` 是初始架构版本，因此本构建写出的文件不涉及任何迁移；而版本号高于本构建的文件会按"尽力打开"处理并明确告知。信封刻意保留文档实际通过校验的那个版本号，而不是重新盖成本构建的版本，以免一个只被部分理解的文件在后续被当作已完整迁移。

### 结构

一个项目文件包含：
- `nodes` — 所有树节点的邻接映射（id、标签、parentId、childrenIds、branchLength、support、age、样式覆盖、性状状态等）。
- `rootId` — 根节点的 id。
- `customEdges` — 网状/特殊连线数组。
- `layout` — 布局类型、方向、模式、间距、时间单位、支持率阈值。
- `canvas` — 画布尺寸和背景。
- `defaults` — 默认节点、分支和连线样式；分支渐变。
- `characters` — 用户定义的性状（离散/连续、状态、代价矩阵）。
- `events` — 标注的演化事件（含因果链链接）。
- `layers` — 命名假说层。
- `activeLayerId` — 当前活跃层。
- `layerStore` — 非活跃层的已保存假说数据。
- `environmentalEvents` — 有年代的环境/地质背景事件。
- `calibrationPoints` — 化石校准点。
- `geneTrees` — 嵌入的基因树（用于 DTL 协同重建）。
- `reconCosts` — DTL 代价参数（加倍、转移、损失）。

### 撤销/重做

CladeForge 使用结构共享（Immer）维护最多 100 步撤销。所有拓扑编辑、样式修改、性状分配和事件放置均可撤销。

### 自动保存与恢复

CladeForge 在工作过程中把工作区自动保存到本地存储，并在下次启动时恢复。状态指示由**真实的写入结果**驱动，而不是由防抖计时器猜测，因此绝不可能出现"写入失败却显示已保存"：

| 指示（悬停可见详情） | 含义 |
|--------------------|------|
| 保存中… | 正在写入本地存储 |
| 已保存 | 自动保存已写入本地存储，重启后可恢复 |
| 自动保存失败 | 未写入！最新改动**只存在于内存**，请立即使用「文件 › 保存项目」 |

自动保存会在本地存储不可用或已写满（通常是项目过大）、文档无法序列化、或写入被拒绝时失败，警告提示条会说明具体原因。自动保存只是崩溃兜底，不能替代保存——只有「保存项目」才会把 `.cladeforge.json` 写入磁盘。

### 最近文件

**文件 › 最近** 列出最近打开的 8 个项目与树文件。桌面版中每条记录都保留完整路径，点击可直接重新打开；Web 版没有路径概念，点击会转为打开文件选择对话框。「清除最近记录」可清空该列表。

## 15. 常见问题

### 选择了"矩形枝长图"但树看起来还是分支图

这发生在树没有枝长数据时。导入带枝长的树（Newick 中含 `:length` 值），或在检视面板中逐个输入枝长。

### 中点定根不可用

中点定根需要枝长数据来计算最长路径。请先添加枝长。

### DTL 求解器报告"需要二叉基因树"

DTL 动态规划求解器需要二叉基因树。多分叉会破坏谱系记账。请先在基因树中解决多分叉。（物种树可以是任意分支数。）

### ASR 饼图显示均匀分布

这可能在以下情况发生：
- 所有末端具有相同状态（无变异可重建）。
- 枝长未记录或无效（按1代入，可能使信号扁平化）。刻意记录为 0 的枝长仍按 0 处理。
- 大树上数值下溢导致后验塌缩（以警告报告）。

请查看 ASR 结果摘要中的警告信息。

### 导出的图片与画布不一致

SVG 导出使用与画布相同的渲染逻辑从零生成。如果语义层（性状、事件、时间轴）在屏幕上处于活跃状态，它将包含在导出中。导出前请确保布局模式、方向和可见层设置如你所愿。

### 应用打开很多标签页时启动较慢

CladeForge 在启动时恢复所有标签页。如果打开了多个大型项目，恢复可能需要片刻。损坏的标签页会被跳过并通知。

### 项目文件较大

项目文件为 JSON 格式，在性状状态、事件和假说层较多时可能变大。这是正常的。格式带显式版本标记，本版本写出的文件在后续版本中仍可打开。

### 文件因过大被拒绝

解析器在数据进入界面之前先行设防：树文本上限 64 MB，项目 JSON 上限 192 MB，单次解析上限 2 000 000 个节点。真实文档远在这些上限之下（一万末端的 Newick 约 250 kB），因此被拒绝通常意味着文件内容与扩展名不符——例如把二进制文件存成了 `.nwk`，或手工编辑后已损坏的项目文件。提示信息会同时给出实际大小与上限。
